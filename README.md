# Rutas de Tapiocapolis — Project Finance Guide

Static GitHub Pages site containing the presentation-study guide for the Case A Project Finance analysis.

The public site includes only the HTML guide and stylesheet. It does not include the original case PDF, Excel model, presentation files, or source documents.

## Local update

1. Update `E:\github\cirkula\case_a_project_finance\Guia_de_Exposicion_y_Preguntas.md`.
2. Regenerate its HTML with Pandoc and the relative `Guia_Exposicion.css` reference.
3. Copy the output to `docs/index.html` and copy the CSS to `docs/Guia_Exposicion.css`.
4. Commit and push to `main`; GitHub Pages publishes from `/docs`.
